# FutbolStats - Trabajo Practico POO

Repositorio de el desarrollo del TPO

### Descripcion
-- El sistema permite al usuario programar un partido, en donde selecciona
los equipos que participan. Luego este tiene la opcion de marcar eventos, con sus
respectivos jugadores. Tambien se le permite observar la tabla de los equipos, estadisticas
de los jugadores y eventos aplicados hacia ellos. --

## Estructura del Repositorio
* '/docs': Documentacion general
* '/docs/uml': Diagramas de diseño (casos de uso, clases, secuencias) y cambios a realizar
* '/src': Todo el codigo del proyecto, subdividido por categorias
* '/test': Algunos tests hechos para mejorar la calidad del codigo y asegurar que funcione como deberia


### Requisitos de Ejecución
Java JDK 17 o superior.
IDE recomendado: IntelliJ IDEA.


### Instrucciones de Instalacion y Ejecucion
Clonar el repositorio en tu maquina.
Abrir el proyecto en un IDE que soporte JAVA fijandose de que la carpeta src este marcada como Sources Root y test como Test Sources Root.
Ejecutar la clase principal ubicada en src/futbolstats/vista/Main.java.
Utilizar el menú interactivo por consola para realizar partidos, registrar eventos y consultar las tablas.
